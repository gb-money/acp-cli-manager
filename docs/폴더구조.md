# 프로젝트 폴더 구조 정리

프로젝트의 소스를 효율적으로 관리하고 에이전트의 파일 생성 위치를 올바르게 지정할 수 있도록 관리합니다.

## 폴더 구조

- src : 프로젝트의 전체 소스를 관리하는 폴더
  - Core : 핵심 로직을 담당하는 폴더
  - Common : 공통 함수를 담당하는 폴더
  - UI : UI 로직을 담당하는 폴더
  - Utils : 유틸리티 함수를 담당하는 폴더
  - Agents : 에이전트 별 제어 관련 로직을 담당하는 폴더 (gemini-cli, claude-code 등 개별 특화 제어 코드)
  - ACP : ACP 관련 로직을 담당하는 폴더
  - Services : 서비스 관련 로직을 담당하는 폴더
  - Data : 데이터 관련 로직을 담당하는 폴더
  - Tests : 테스트 관련 로직을 담당하는 폴더
  
- Resources : 리소스 관련 로직을 담당하는 폴더
